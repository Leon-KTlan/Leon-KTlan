**by Leon / [@Leon-KTlan](https://github.com/Leon-KTlan)**

**AI Agent & Backend Builder**

I build traceable AI agents and backend systems that can be run, inspected, and verified.

我专注于构建可运行、可追溯、可审阅的智能体与后端系统。

## What I work on

- Agent orchestration, tool calling, streaming execution traces, and evidence chains
- Backend and data workflows with TypeScript, Python, PostgreSQL, Redis, and queues
- Open-source Agent Skills that turn external tools and live data into useful workflows
- Engineering practices that keep AI-assisted systems observable and testable

## Selected work

| Project | What it demonstrates |
| --- | --- |
| [Warehouse Exception Diagnosis Agent](https://github.com/Leon-KTlan/pkg-exception-diagnosis-demo) | A React and TypeScript Agent demo with SSE execution traces, tool calls, evidence-backed answers, retries, cancellation, and deterministic demo scenarios. |

## Current focus

- Making Agent execution easier to inspect and debug
- Designing reliable human-in-the-loop data workflows
- Improving documentation, tests, and contributor experience across my open-source projects
